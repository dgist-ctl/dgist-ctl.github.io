클로드 실전 가이드

설치부터 포털 자동화, 내 업무를 스킬로 만드는 것까지 순서대로 따라 하는 안내서입니다. 명령어는 오른쪽 위 복사 버튼으로 그대로 붙여 넣으면 됩니다. 모든 명령은 Windows 11의 PowerShell에서 실행합니다.

설치→대화→포털 창(CDP 9223)→관측→스킬

STEP 0준비물

한 번만 갖춰 두면 됩니다.

무엇왜 필요한가확인 방법
Claude 유료 계정Pro 또는 Max 구독이 있어야 Claude Code에 로그인됩니다.claude.ai 로그인
Git for WindowsClaude Code가 Windows에서 명령을 실행할 때 Git Bash를 씁니다.git --version
Python 3.11 이상포털 자동화(Playwright)와 관측기 스크립트를 돌립니다.python --version
학내망 또는 VPN포털·전자결재·웹메일은 학외에서 바로 열리지 않습니다.portal.dgist.ac.kr 접속

PowerShell은 시작 메뉴에서 “PowerShell”을 검색해 엽니다. 관리자 권한은 필요 없습니다.

POWERSHELL · Git·Python 한 번에 설치
winget install --id Git.Git -e
winget install --id Python.Python.3.12 -e
확인PowerShell 창을 닫았다 다시 연 뒤 git --version, python --version이 버전 숫자를 보여 주면 됩니다.

STEP 1Claude Code 설치

공식 설치 스크립트 한 줄이면 끝납니다. Node.js는 따로 필요 없습니다.

  1. 설치 스크립트 실행
    POWERSHELL
    irm https://claude.ai/install.ps1 | iex

    “실행 정책” 오류가 나면 아래 줄을 먼저 실행하고 다시 시도합니다(현재 사용자에게만 적용).

    POWERSHELL
    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  2. 새 PowerShell 창에서 실행
    POWERSHELL
    cd $HOME
claude

    처음 실행하면 브라우저가 열립니다. Claude 계정으로 로그인하고 승인을 누르면 터미널로 돌아옵니다. 테마 선택, 폴더 신뢰 여부 질문은 기본값으로 진행해도 됩니다.

  3. 설치 점검
    POWERSHELL
    claude --version
claude doctor
    확인claude doctor에 빨간 오류가 없으면 설치 완료입니다.
어느 폴더에서 켜나요? Claude는 켠 폴더를 작업 공간으로 봅니다. 처음에는 내 홈 폴더(C:\Users\내아이디)에서 켜고, 특정 업무를 할 때는 그 업무 폴더로 cd 한 뒤 켜는 습관을 들이세요.

STEP 2첫 대화와 기본기

명령어를 외울 필요는 없습니다. 하고 싶은 일을 한국어로 말하면 됩니다.

바탕화면에 있는 엑셀 파일들 목록 보여줘
D:\업무\설문결과.xlsx 열어서 문항별 평균 정리해줘
이 폴더에 있는 hwp 파일을 모두 docx로 바꿔줘

Claude가 파일을 고치거나 명령을 실행하기 전에 허용 여부를 묻습니다. 무엇을 하려는지 읽어 보고 Yes를 누르세요. 모르겠으면 No를 누르고 “왜 그게 필요해?”라고 물으면 됩니다.

자주 쓰는 키와 명령

입력하는 일
EscClaude가 하던 일을 멈춥니다. 방향이 틀렸다 싶으면 바로 누르세요.
Esc 두 번앞 메시지로 돌아가 다시 씁니다.
Shift+Tab허용 모드를 바꿉니다(매번 묻기 ↔ 편집 자동 허용 ↔ 계획만 세우기).
/clear대화를 비우고 새로 시작합니다. 주제가 바뀌면 쓰세요.
/skills설치된 스킬 목록을 봅니다.
! 명령맨 앞에 !를 붙이면 그 줄을 내가 직접 실행합니다(예: ! python --version).
@파일대화에 파일을 지정합니다(예: @보고서.docx 요약해줘).

기억 시키기: CLAUDE.md

C:\Users\내아이디\.claude\CLAUDE.md에 적어 둔 내용은 매 대화 시작 때 Claude가 읽습니다. “보고서는 docx로”, “이메일은 존댓말로”처럼 매번 반복하던 말을 여기에 적어 두면 됩니다. 대화 중에 “이거 기억해줘”라고 해도 됩니다.

STEP 3크롬 CDP로 포털 접속

Claude가 포털 화면을 읽고 누를 수 있도록, 원격 조종 포트가 열린 포털 전용 크롬을 하나 띄우는 단계입니다.

① 포털.cmd더블클릭하면 전용 크롬이 9223 포트로 열림
② 직접 로그인처음 한 번은 사람이 인증서·SSO 로그인
③ 세션 유지전용 프로필에 로그인이 남아 다음부터 자동
④ Claude 연결스크립트가 9223에 붙어 화면을 읽고 조작
왜 평소 쓰는 크롬이 아닌가요? 크롬은 보안상 기본 프로필에 원격 조종 포트를 열지 못하게 막습니다(Chrome 136부터). 그래서 별도 프로필 폴더를 쓰는 Chrome for Testing을 따로 띄웁니다. 창 제목 끝이 “Chrome for Testing”이면 전용 창입니다. 개인 크롬과 섞이지 않아 즐겨찾기·비밀번호도 안전합니다.
  1. Playwright와 전용 크롬 설치
    POWERSHELL
    pip install playwright
python -m playwright install chromium

    설치가 끝나면 %LOCALAPPDATA%\ms-playwright\chromium-숫자\chrome-win64\chrome.exe가 생깁니다. 숫자는 버전마다 다릅니다.

  2. 바탕화면에 포털.cmd 만들기

    메모장에 아래 내용을 붙여 넣고 파일 형식: 모든 파일, 이름 포털.cmd로 바탕화면에 저장합니다. 첫 줄 CHROME 경로의 숫자는 위에서 확인한 폴더 이름으로 바꾸세요. 주석은 영어로 둡니다(한글 주석은 cmd에서 깨집니다).

    포털.cmd
    @echo off
REM DGIST portal launcher: dedicated Chrome with CDP port 9223
set "CHROME=%LOCALAPPDATA%\ms-playwright\chromium-1223\chrome-win64\chrome.exe"
set "PROFILE=%USERPROFILE%\.claude-portal-profile"
set "PORT=9223"

powershell -NoProfile -Command "try { (New-Object Net.Sockets.TcpClient).Connect('127.0.0.1',%PORT%); exit 0 } catch { exit 1 }"
if %ERRORLEVEL%==0 ( echo Already running on %PORT%. & exit /b 0 )

start "" "%CHROME%" --remote-debugging-port=%PORT% --user-data-dir="%PROFILE%" ^
  --disable-popup-blocking --disable-backgrounding-occluded-windows ^
  --disable-renderer-backgrounding https://portal.dgist.ac.kr

    이미 9223이 열려 있으면 새 창을 띄우지 않고 기존 창을 그대로 씁니다. 두 번 눌러도 괜찮습니다.

  3. 더블클릭 → 직접 로그인

    처음 한 번은 사람이 로그인합니다. 로그인 정보는 .claude-portal-profile 폴더에 남아 다음부터는 대개 자동으로 들어가집니다. 비밀번호를 Claude에게 알려 주거나 파일에 적지 마세요.

  4. 연결 확인

    포털 창이 열린 상태에서 일반 브라우저로 아래 주소를 열면 JSON 글자가 보여야 합니다.

    주소창
    http://127.0.0.1:9223/json/version

    Claude에게 이렇게 말해 보세요.

    9223 포트 크롬에 붙어서 지금 열린 탭 제목들 알려줘

    Claude는 내부적으로 아래와 같은 코드를 씁니다. 직접 짤 필요는 없지만 원리를 알아 두면 오류를 읽기 쉽습니다.

    PYTHON · 연결 원리
    from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.connect_over_cdp("http://127.0.0.1:9223")
    ctx = browser.contexts[0]          # 내가 로그인해 둔 그 창
    for page in ctx.pages:
        print(page.title(), page.url)
    # browser.close() 를 부르지 않는다 → 창이 닫히지 않음
    확인포털 탭 제목과 주소가 출력되면 성공입니다. 이제 Claude가 이 창을 보고 누를 수 있습니다.

웹메일은 포털 안에서 들어갑니다

포털과 웹메일은 로그인 세션이 따로입니다. 웹메일 주소로 바로 가면 비밀번호 화면이 뜹니다. 포털 첫 화면의 메일 링크로 들어가면 SSO로 자동 로그인됩니다. Claude에게도 “포털 메일 링크로 웹메일 열어줘”라고 말하면 됩니다.

STEP 4관측기로 스킬 만들기

반복하는 포털 업무를 Claude가 대신 하게 만드는 가장 빠른 길입니다. 화면을 뒤져서 추측하게 하지 말고, 내가 평소대로 한 번 하는 것을 기록하게 합니다.

왜 관측부터인가

화면만 보고는 알 수 없는 것들이 있습니다. 주소 끝에 붙은 파라미터 하나로 계정이 바뀌는 경우, 입력 칸이 iframe 안에 숨어 있는 경우, 타일을 눌러야 입력란이 생기는 경우 같은 것입니다. 실제로 Commons 업로드 스킬을 만들 때 Claude가 40분 동안 화면을 탐색한 것보다 사람이 15분 시연한 기록이 더 정확했습니다.

관측기는 포털 창(9223)에 붙어서 기록만 합니다. 대신 누르거나 입력하지 않고, 경고창도 사람이 직접 처리합니다. 비밀번호 칸에 입력한 값은 ***로 가려 저장합니다.

  1. 자동화하고 싶은 일을 한 문장으로
    매주 하는 카드 지급신청을 스킬로 만들고 싶어. 관측기 켜줘

    Claude가 “어느 화면에서 무엇을 누르시나요?”라고 되물으면 화면 이름 정도만 답하면 됩니다.

  2. 관측 시작 후 평소대로 작업

    Claude가 관측기를 백그라운드로 켭니다. 지켜야 할 것은 세 가지뿐입니다.

    규칙이유
    포털 창에서만개인 크롬에서 한 일은 기록되지 않습니다.
    확인창은 직접관측기는 아무것도 대신 누르지 않습니다.
    끝나면 “끝”Claude가 관측기를 끄고 기록을 정리합니다.

    실수로 잘못 눌렀다가 되돌려도 괜찮습니다. 평소 속도로 하세요. 큰 파일을 내려받는 단계가 있으면 그 단계는 관측을 끈 뒤에 하거나 따로 말해 주세요(관측 중에는 다운로드가 임시 폴더로 빠집니다).

  3. 기록 요약 받기

    “끝”이라고 하면 Claude가 기록을 시간순 타임라인으로 정리합니다. 아래는 실제 요약의 일부입니다.

    요약.md · 관측 예시(LMS, 식별자는 바꿈)
    09:24:31  CLICK  ul#base_tools > a | text='코스'
09:24:31  GOTO   https://lms.dgist.ac.kr/ultra/course
09:24:48  CLICK  a#course-link-_12345_1 | text='예시 과목'
09:24:57  CLICK  button#folder-title-_100001_1 | text='6주차'
09:25:04  CLICK  button#add-content-menu-button-start-_100001_1
09:25:09  CLICK  li > span | text='Content Market'
09:25:09  GOTO   .../outline/contentmarket?parentId=_100001_1
    표시뜻
    CLICK / INPUT내가 누른 요소와 입력한 값
    FILE선택한 첨부 파일 이름과 크기
    GOTO페이지 이동
    REQ / RES화면 뒤에서 오간 서버 요청과 응답
    (frame …)그 요소가 iframe 안에 있다는 표시. 자동화할 때 가장 자주 놓치는 부분입니다.
  4. 절차표 검토

    Claude가 기록을 단계 | 사람이 한 일 | 스크립트가 쓸 방법 | 되돌릴 수 없는 지점 표로 바꿔 보여 줍니다. 여기서 사람이 할 일은 하나입니다. “되돌릴 수 없는 지점”(저장, 신청, 상신, 발송)이 맞게 표시됐는지 확인하는 것입니다.

  5. 스킬로 만들고 실제 1건 시험

    Claude가 설계 → 계획 → 코드 → 테스트 순서로 스킬을 만듭니다. 마지막에 실제 업무 1건을 내가 지켜보는 앞에서 돌려 보고, 달라진 점을 스킬 설명서에 반영하면 완성입니다.

    완성된 스킬의 모양
    C:\Users\내아이디\.claude\skills\카드지급신청\
├─ SKILL.md        # 언제 쓰는지·절차·금지사항 (Claude가 읽는 설명서)
├─ scripts\        # 실제로 포털을 조작하는 파이썬
└─ tests\          # 고장 났는지 확인하는 테스트

    이후에는 /카드지급신청이라고 치거나 “카드 지급신청 해줘”라고 말하면 그 스킬이 실행됩니다.

관측기가 맞지 않는 일 브라우저 밖 작업(엑셀 정리, 문서 작성, 파일 변환)은 관측할 화면이 없습니다. 이런 일은 “이 작업을 스킬로 만들어줘”라고 하면 Claude가 다른 방식(skill-creator)으로 만듭니다.

STEP 5안전 규칙

포털은 돈과 결재가 오가는 곳입니다. 아래 원칙을 스킬마다 지킵니다.

구분Claude가 하는 일사람이 하는 일
조회·검색·다운로드바로 실행결과 확인
저장·임시저장채운 값을 미리 보여 주고 확인 후 실행미리보기 검토 후 승인
상신·결재요청·신청하지 않음직접 버튼 클릭
메일 발송초안 작성, 내 주소로 테스트 발송초안 확인 후 실제 발송 승인
삭제하지 않음필요하면 직접

비밀번호·인증서 암호는 대화나 파일에 적지 않습니다. 로그인은 언제나 사람이 전용 크롬 창에서 직접 합니다.

STEP 6막혔을 때

증상해결
claude 명령을 못 찾음PowerShell 창을 새로 열기. 그래도 안 되면 설치 스크립트를 다시 실행하고 claude doctor.
포털.cmd를 눌러도 창이 안 뜸CHROME 경로의 chromium 숫자가 실제 폴더와 같은지 확인.
9223은 응답하는데 연결이 멈춤전용 크롬만 종료 후 포털.cmd 재실행(아래 명령). 개인 크롬 탭은 닫히지 않습니다.
포털 화면이 비어 있음로그인 문제로 단정하지 말고 먼저 새로고침(F5). 빈 탭은 닫기.
한글이 ??? 로 깨짐실행 전 $env:PYTHONUTF8=1. cmd 파일에는 한글 주석을 쓰지 않기.
학교 밖에서 포털 안 열림VPN 연결 후 다시 시도.
POWERSHELL · 전용 크롬만 종료 후 재시작
$udd = "$env:USERPROFILE\.claude-portal-profile"
(Get-CimInstance Win32_Process -Filter "Name='chrome.exe'" |
  Where-Object { $_.CommandLine -like "*$udd*" }).ProcessId |
  ForEach-Object { Stop-Process -Id $_ -Force -ErrorAction SilentlyContinue }
Start-Process "$env:USERPROFILE\Desktop\포털.cmd"

그래도 모르겠으면 오류 메시지를 그대로 Claude에게 붙여 넣고 “이거 왜 나?”라고 물어보세요. 대부분 그 자리에서 원인을 찾습니다.
