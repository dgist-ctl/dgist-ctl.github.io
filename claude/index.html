시작 전에먼저 알아 둘 말 다섯 개

클로드 코드내 컴퓨터에 사는 AI 비서말로 부탁하면 파일을 열고, 정리하고, 프로그램도 대신 실행해 줍니다.
PowerShell클로드와 대화하는 창글자만 있는 검은(파란) 창입니다. 클로드는 이 창 안에서 일합니다.
CDP 연결클로드 손에 쥐여 주는 크롬 리모컨이게 연결되면 클로드가 포털 화면을 보고 대신 누를 수 있습니다.
스킬클로드의 업무 요령서한 번 가르쳐 두면 “○○ 해줘” 한마디로 같은 일을 반복합니다.
관측기옆에서 받아 적는 도우미내가 포털에서 일하는 순서를 적어 두면, 클로드가 그걸로 요령서를 만듭니다.

1단계 · 약 15분준비물 4가지 갖추기

구독 1개와 프로그램 3개입니다. 버튼을 ①부터 차례로 누르세요.

①Claude 구독Pro 또는 Max 요금제를 고릅니다. 이미 쓰고 있으면 건너뛰세요. ②Git“64-bit Git for Windows Setup”을 받습니다. 질문이 많지만 전부 Next. ③Node.js“Windows 설치 프로그램(.msi)”을 받습니다. 전부 Next. ④Python맨 위 “Latest Python 3”을 받습니다. 아래 그림의 칸에 꼭 체크!

받은 파일은 화면 오른쪽 위(또는 다운로드 폴더)에 있습니다. 더블클릭해서 설치합니다.

④ Python에서 가장 많이 틀립니다. 설치 첫 화면 맨 아래 이 칸에 체크하고 Install Now를 누르세요.
✓Add python.exe to PATH
체크를 빠뜨렸으면 설치 파일을 다시 실행해 Uninstall한 뒤 다시 깔면 됩니다.
성공네 개 모두 “Setup was successful” 또는 “완료”가 나왔으면 됩니다. 제대로 깔렸는지는 2단계에서 클로드가 확인해 줍니다.
왜 4개나 필요한가요?

Git은 클로드가 컴퓨터에 일을 시킬 때, Node.js는 Word·PowerPoint 문서를 만들 때, Python은 포털 일을 할 때 씁니다. 클로드만 쓰려면 Git 하나로도 되지만, 이 가이드의 4·5단계까지 하려면 넷 다 필요합니다.

4단계 · 약 10분포털 연결(CDP)

클로드에게 포털 전용 크롬의 리모컨(CDP)을 쥐여 주는 단계입니다. 어려운 일은 클로드가 합니다. 나는 부탁하고, 로그인만 하면 됩니다.

왜 평소 크롬이 아닌가요? 평소 크롬은 보안 때문에 리모컨 연결이 막혀 있습니다. 그래서 포털만 여는 크롬을 하나 더 둡니다. 평소 크롬의 즐겨찾기·비밀번호는 그대로입니다.
  1. 아래 글을 복사해서 클로드에게 붙여 넣기
    클로드 창에 붙여 넣기
    포털을 CDP로 연결해 줘.
1) Playwright와 전용 크롬(chromium)을 설치해 줘.
2) 바탕화면에 '포털.cmd'를 만들어 줘. 더블클릭하면 전용 크롬이 CDP 포트와 전용 프로필로 https://portal.dgist.ac.kr 을 열고, 이미 열려 있으면 새 창을 띄우지 않게. cmd 파일 주석은 영어로.
3) 다 되면 포털.cmd를 한 번 실행해 줘.

    “해도 될까요?”가 몇 번 나오면 모두 1. Yes. 몇 분 뒤 크롬 창이 하나 뜹니다.

  2. 새로 뜬 창에서 직접 로그인

    창 제목 끝에 “Chrome for Testing”이라고 쓰인 창이 포털 전용 크롬입니다. 여기서 평소처럼 포털에 로그인하세요.

    주의비밀번호는 절대 클로드 창에 쓰지 마세요. 로그인은 언제나 내가 합니다. 한 번 로그인하면 다음부터는 대개 저절로 들어가집니다.
  3. 연결됐는지 확인
    CDP로 연결된 포털 창에 무슨 탭이 열려 있는지 알려줘
    성공클로드가 “DGIST 포털” 같은 탭 이름을 말해 주면 연결된 것입니다. 이제 “포털에서 내 예산 현황 조회해줘” 같은 부탁을 해 보세요.

내일부터는

포털은 바탕화면의 포털.cmd를 더블클릭해서 여세요. 그 창이 열려 있어야 클로드가 포털 일을 할 수 있습니다.

원리가 궁금한 분만

CDP(Chrome DevTools Protocol)는 크롬이 바깥 프로그램에게 “화면 읽기·클릭”을 허락하는 통로입니다. 포털.cmd는 이 통로를 연 채로 크롬을 띄우고, 클로드는 Playwright라는 도구로 그 통로에 붙습니다. 통로 번호(포트)는 클로드가 정해 포털.cmd에 적어 둡니다.

웹메일은 포털과 로그인이 따로입니다. 포털 첫 화면의 메일 링크로 들어가야 다시 로그인하지 않아도 됩니다.

5단계 · 일 하나에 15분내 일 가르치기(관측기)

신입 직원 가르치듯 하면 됩니다. 말로 설명하지 말고, 한 번 해 보이세요.

관측기는 내가 포털 전용 크롬에서 무엇을 눌렀고 무엇을 입력했는지 받아 적기만 합니다. 대신 누르지 않습니다. 비밀번호는 ***로 가려서 적습니다.

먼저 준비 4단계(포털 연결)를 끝내야 합니다. 관측기 프로그램은 교수학습센터가 만든 것이라, 처음 한 번은 센터에 설치를 요청하세요.
  1. 가르칠 일을 한 문장으로 말하기
    매달 하는 카드 지급신청을 스킬로 만들고 싶어. 관측기 켜줘
  2. 포털 전용 크롬에서 평소처럼 한 번 하기
    약속이유
    포털 전용 크롬에서만평소 크롬에서 한 일은 적히지 않습니다.
    확인창은 내가 누르기관측기는 아무것도 대신 누르지 않습니다.
    다 하면 클로드에게 “끝”그때 기록을 마칩니다.

    천천히 해도, 잘못 눌렀다 되돌려도 괜찮습니다. 마지막 신청·상신 버튼은 누르지 않고 멈춰도 됩니다.

  3. 클로드가 만든 순서표 확인하기

    클로드가 “① 카드사용내역 열기 → ② 날짜 고르기 → ③ 지급신청 누르기 …”처럼 정리해 보여 줍니다. 저장·신청·발송처럼 되돌릴 수 없는 곳에 표시가 잘 됐는지만 봐 주세요.

  4. 진짜 일 1건으로 시험하기

    스킬이 만들어지면 내가 보는 앞에서 실제 1건을 해 봅니다. 틀린 곳은 그 자리에서 말하면 고칩니다.

    완성다음부터는 “카드 지급신청 해줘” 한마디면 클로드가 그 순서대로 합니다.
받아 적은 기록은 이렇게 생겼어요
관측 기록 예시(과목명은 바꿈)
09:24:31  CLICK  '코스'          ← 누른 것
09:24:31  GOTO   lms…/course     ← 이동한 화면
09:24:48  CLICK  '예시 과목'
09:24:57  CLICK  '6주차'
09:25:09  CLICK  'Content Market'

화면만 봐서는 모르는 숨은 단계(창 안의 창, 주소 뒤에 붙은 값)까지 적히기 때문에, 클로드가 혼자 화면을 뒤지는 것보다 훨씬 빠르고 정확합니다.

엑셀 정리나 문서 만들기처럼 포털이 아닌 일은 관측기 없이 “이 작업을 스킬로 만들어줘”라고 말하면 됩니다.

궁금한 것자주 묻는 질문

구독료 말고 돈이 더 드나요?

Pro·Max 구독 안에서 씁니다. 따로 결제되지 않습니다. 많이 쓰면 잠시 사용 한도에 걸릴 수 있고, 몇 시간 뒤 다시 풀립니다.

내 파일이 밖으로 나가나요?

클로드가 읽은 내용은 답을 만들기 위해 Anthropic(클로드 회사) 서버로 보내집니다. 개인정보·학생 성적처럼 민감한 파일은 클로드에게 열게 하기 전에 한 번 더 생각하세요.

클로드가 실수로 파일을 지우면요?

지우거나 고치기 전에 반드시 “해도 될까요?”라고 묻습니다. 모르면 3번(No)을 고르세요. 중요한 폴더는 미리 복사본을 두면 더 안심입니다.

영어를 못 해도 되나요?

됩니다. 한국어로 묻고 한국어로 답을 받습니다. 처음 설치할 때 나오는 영어 질문 몇 개는 2단계 그림대로 고르면 됩니다.

막혔을 때안 될 때

제일 쉬운 방법: 빨간 글씨를 통째로 복사해서 클로드에게 “이거 왜 나?”라고 물어보세요.

이럴 때이렇게
claude를 쳐도 “인식되지 않습니다”PowerShell 창을 닫고 새로 열기. 그래도 안 되면 2단계 한 줄을 다시 붙여 넣기.
포털.cmd를 눌러도 창이 안 뜸클로드에게 “포털.cmd가 안 열려. 고쳐줘”.
